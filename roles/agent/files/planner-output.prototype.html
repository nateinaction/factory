Planner output: prototype

Throwaway. Answers Format of the Planner's output for the factory script.

The question: what file should the Planner write so the factory script can apply it to GitHub, given that the model holds no token and every effect must be safe to apply twice?
The idea on trial: the Planner writes only two kinds of output, a round of questions or a final round. A final round carries the full proposal (spec, slices, map, or a resolution) inside the factory's own comment. When a writer answers "yes", the script applies that stored proposal with no model run, so what gets created is exactly what the writer approved. Every created thing carries a hidden key, so re-applying after a crash creates nothing twice.
